## 🚀 Getting Started (This Week)

### Step 1: Read the Main Assignment (30 min)
Open **AI-Agent-Capstone-Assignment.md**
- Skim sections 1–4 (overview, objectives, timeline)
- Pick a project idea from section "Project Ideas"
- Understand success criteria (section "Grading Rubric")

### Step 2: Define Your Agent (1–2 hours)
Use **AGENT-PRD-TEMPLATE.md**
1. Fill in: 1-liner, problem, solution
2. List 3–5 core features
3. Pick your tech stack
4. Define 2–3 success metrics

Save as `MY-AGENT-PRD.md` in your project folder.

### Step 3: Set Up Your Workspace
- Create folder: `~/my-agent-capstone/`
- Copy all markdown files there
- Create subfolders: `backend/`, `web/`, `docs/`, `tests/`
- Initialize Git: `git init`

### Step 4: Read Tech Stack Guide (1 hour)
Skim **TECH-STACK-GUIDE.md**
- Don't memorize; just familiarize yourself
- Bookmark for reference during implementation
- Keep it open during Weeks 3–5 (building phase)

### Step 5: Create Week 1 Plan
From **WEEK-BY-WEEK-CHECKLIST.md**, Week 1 section:
- Print or copy daily checklist
- Assign times: Mon–Fri, when will you work?
- Set calendar reminders

## ❓ FAQ

**Q: How much time per week?**  
A: 15–20 hrs/week is realistic for shipping quality work. Some weeks (5–6) are heavier; others are lighter.

**Q: Do I need to know all the tech?**  
A: No. You'll learn by doing. Week 1–2 gets you foundations. Weeks 3–8 are hands-on.

**Q: What if I get stuck?**  
A: Reference docs, Google the error, ask in communities. This is 90% of real engineering.

**Q: Can I change my idea mid-way?**  
A: Better to pivot early (Week 2) than late. If your idea isn't working, discuss with me.

**Q: What if I don't finish?**  
A: Ship what you have. A working MVP beats an unfinished grand idea. You can add features after the capstone.
